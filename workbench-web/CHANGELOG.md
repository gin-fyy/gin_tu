# 更新日志

> 发版时在这里加一段（最新的放最上面）。打包脚本会把**对应版本那一段**写进 `version.json` 的 `notes`，
> App 的更新弹窗就显示这些内容。写法：`## 版本号` 开头，下面每行用 `- ` 列一条。

## 1.1.4

- 你现在看到的这个更新弹窗和更新日志，就是本次要验证的功能
- 更新日志改成自动从 CHANGELOG.md 生成，以后每次发版都会显示本次改了什么
- 优化：更新源连不上时静默跳过，不打扰正常使用

## 1.1.3

- 新增「App 内更新」：发现新版本时自动弹窗，并显示本次更新内容
- 新增应用内一键更新：在 App 里下载安装包并直接拉起系统安装，不用再去浏览器找下载页
- 更新地址支持多行：可同时填 CDN 与局域网地址，App 会依次尝试、谁通用谁
- 修复：第一个更新源失败后没有自动切换到下一个地址

## 1.1.2

- 完成任务时二次确认（默认开启，可在「我的 → 偏好设置」关闭）
- 内置默认更新地址，装完不用手填就能检查更新

## 1.1.1

- 完成任务二次确认（防误触）
- APK 版本号自动写入，App 内可「检查更新」与「检查热更新」
