# 更新日志

> 发版时在这里加一段（最新的放最上面）。打包脚本会把**对应版本那一段**写进 `version.json` 的 `notes`，
> App 的更新弹窗就显示这些内容。写法：`## 版本号` 开头，下面每行用 `- ` 列一条。

## 2.0.1

- **桌宠清晰度**：立绘从 229×360 放大到 **458×720 并用锐化（UnsharpMask）处理**，浮窗里不再糊
- **体型变小**：默认 **108 dp**（原来 168 dp 太大），滑块范围 64–240 dp，改大小会自动重新钳制位置
- **再也不会跑出屏幕**：位置加了**四边钳制**（拖动、甩抛、改大小都会夹回屏幕内），初始位置改到屏幕左侧偏上
- **更好控制**：「让它自己溜达」开关——关掉就待在原地，方便摆位置；长按 1.6 秒可收起桌宠
- 壁纸也确认修好（你的截图已能看到照片）；壁纸"模糊"是源图 410×890 太小，换长边 ≥1440 的图即可

## 2.0.0

- **新增「桌宠浮窗」**（我的 → 桌宠浮窗）：把桌宠放到**系统最上层**，悬浮在微信/浏览器之上
  - 透明背景、可拖动、**甩出去有惯性**、自己会溜达（走→停→偶尔转身）；点一下会跳起来并有回应
  - 大小可调（96–300 dp 滑块），「放出来 / 收起来」一键切换
  - 需要系统权限「显示在其他应用上层」（面板上有授权按钮，点了会跳到系统设置）
  - 不联网、无 AI，纯本地
- 壁纸读大图加了 1.5 秒兜底 + **先用缩略图立即显示**（修「img src 为空 / 壁纸空白」）
- 版本号到 2.0：从"任务 App"变成"任务 + 课表 + 养成 + 桌宠"

## 1.9.4

- **修「3D 组件一直未加载」的真因**：旧 Service Worker 被注销后，**当前页面在刷新前仍被它接管**，所以脚本请求继续挂着 → 现在注销完会**自动强制刷新一次**（带标记，不会循环刷新）
- 脚本加载加了 **8 秒超时**：再也不会"静默挂住"，诊断里会直接出现 `加载超时：vendor/three.min.js` 之类的明确原因
- **壁纸选图时提示源图太小**：源图宽度 < 720 会提示「这张图只有 410×890，铺满屏幕会模糊，建议长边 ≥1440」——糊是因为源图分辨率不够，不是压缩的问题
- 确认壁纸链路已修复（诊断实测：`完整图 115KB / 缩略图 17KB / img 410×890 / blob:` 全部正常）

- 新增「粘贴课表导入」：本地规则解析（不用联网、不花钱、不用 AI Key），认「周一 1-2节 高等数学 教三101」这类写法，也能认「@实验楼B203」「1-16周」「单周/双周」；识别不了的行会单独列出来
- 新增「轮盘」：抽今天吃什么，或从「未完成的任务」里随机抽一个；选项可自己填
- 新增界面「透明度」调节（50-100%）与「液态玻璃效果」开关（磨砂玻璃质感 + 强度可调）
- 课表里点课程格子即可编辑 / 删除

## 1.2.2

- 新增「外观 · 壁纸」：内置 5 张壁纸（樱花 / 夜色 / 薄荷 / 蜜桃 / 墨玉），也能选自己相册里的照片
- 支持调整遮罩浓度（0-80%）：壁纸太亮时拉高一点，文字照样清楚；卡片自动变半透明

- 下一步计划：AI 添加课表

## 1.2.1
