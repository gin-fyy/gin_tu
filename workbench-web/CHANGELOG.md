# 更新日志

> 发版时在这里加一段（最新的放最上面）。打包脚本会把**对应版本那一段**写进 `version.json` 的 `notes`，
> App 的更新弹窗就显示这些内容。写法：`## 版本号` 开头，下面每行用 `- ` 列一条。

## 1.3.4

- 修复：图片识别课表时输出会被截断（请求没设 max_tokens，长课表只返回一半 → 看起来像"识别不出来"），现在给到 4096
- 课表文字导入：支持「第5周 / 5周」这种只上一周的写法（正方教务系统课表常见）
- 图片识别的提示词按「列=星期、行=节次」的网格重新说明，减少串行串列；实测免费模型读真实教务系统截图仍然不够准，重要课表建议用「粘贴文字导入」

## 1.3.3

- 新增：课表「节次时间」可自己改（原来写死了默认作息）——点课表页的「节次时间」，一行一节填「1 08:00-08:45」
- 新增：AI 配置里的「测试连接」按钮，会直接把真实错误（状态码/原因）显示出来，方便定位图片识别为什么失败
- 图片识别加固：识别超时保护（90 秒）、图片过大自动二次压缩、失败时给出排查建议
- 网络层改用原生 HTTP（CapacitorHttp）：绕开 WebView 的一些网络限制，接口调用更稳

## 1.3.2

- 课表图片识别：提示词改成「逐格扫描、不许漏课、课程名严格照抄」，实测 8 门课全部识别正确（之前会漏课、还会把「大学物理」写成「大学物理实验」）
- 课表图片识别：解析器加强容错 —— 视觉模型偶尔把 JSON 的冒号写成逗号，现在会自动修好（实测模型确实这么写，修完 8/8 全对）；就算它完全不按 JSON 输出，也会退回按行解析
- 默认走 glm-4v-flash（有免费额度）；更强的 glm-4v-plus 需要账户余额（实测未充值会返回「余额不足」）

## 1.3.1

- 新增「课表 · 选图片识别」：拍/选一张课表截图，交给视觉大模型读成课程，先预览再导入（需要你填一个 AI Key，推荐智谱 glm-4v-flash，有免费额度；Key 只存本机）
- 修复：液态玻璃效果与透明度原来只作用在「我的」页的卡片上，现在任务卡、统计卡、筛选胶囊、分段控件、课表格子、弹层等**所有界面**都跟着变
- 顺手修：发布脚本遇到只读文件会崩（曾导致 docs/ 没更新、手机收不到更新），现在会自动清掉只读位重试

## 1.3.0

- 新增「课表」页：周一到周日 × 节次的课表网格，可切换周次、隐藏周末、设置学期首周（单双周才算得准）
- 新增「粘贴课表导入」：本地规则解析（不用联网、不花钱、不用 AI Key），认「周一 1-2节 高等数学 教三101」这类写法，也能认「@实验楼B203」「1-16周」「单周/双周」；识别不了的行会单独列出来
- 新增「轮盘」：抽今天吃什么，或从「未完成的任务」里随机抽一个；选项可自己填
- 新增界面「透明度」调节（50-100%）与「液态玻璃效果」开关（磨砂玻璃质感 + 强度可调）
- 课表里点课程格子即可编辑 / 删除

## 1.2.2

- 新增「外观 · 壁纸」：内置 5 张壁纸（樱花 / 夜色 / 薄荷 / 蜜桃 / 墨玉），也能选自己相册里的照片
- 支持调整遮罩浓度（0-80%）：壁纸太亮时拉高一点，文字照样清楚；卡片自动变半透明
- 自选照片会先压到 1080px / JPEG 再存本机，不会把存储撑爆；随时可一键「恢复默认背景」
- 下一步计划：AI 添加课表

## 1.2.1

- 修复：下载偶尔卡住不动（实测 jsDelivr 对本仓库会卡在 0 KB/s）——单个源 60 秒没数据就换下一个
- 调整内置源顺序：把实测最快的镜像放最前面（gh-proxy 约 257 KB/s、ghfast 约 130 KB/s），jsDelivr 挪到最后
- 新增：应用内下载加了一道总超时（4 分钟），任何源卡死都会自动换源，不会一直转圈

## 1.2.0

- 这一版主要用来验收「更新弹窗 → 应用内下载 → 安装」整条链路
- 新增「恢复默认」按钮：更新地址被改坏了，一键回到内置的 5 个更新源，不用再手打长网址
- 「更新地址」的说明改成真实行为：多个源是**同时问、取版本最新的那个**（不是从上往下试）

## 1.1.9

- 修复：更新地址被填成某个固定/过期地址时（例如某个 commit 固定地址），App 会一直提示「已是最新」而不弹更新
- 现在会把你填的源和内置的 5 个源**一起检查**、取版本最新的那个 —— 地址填错也不会再漏掉新版本

## 1.1.8

- 修复：「我的」页显示的版本号比实际装的旧一版（打包时版本信息写得太晚，APK 里带的是上一版的）
- 修复后不会再出现「明明装的是新版，却一直提示要更新」的情况
- 新增自动检查：APK 里带的版本信息必须和源码版本一致，否则打包自检直接报错

- 更新检查会自动跳过那些还缓存着旧版本的镜像，所以不会再出现「明明有新版本却提示已是最新」
